# ⚙️ AutoLISP Routines for AutoCAD

This repository contains a collection of **custom AutoLISP routines** designed to automate 
repetitive tasks in AutoCAD, focused on piping layouts and accessories.

## 🔹 Main Routines
- [DN.lsp](docs/dn.md) → Custom command to draw pipes with diameter notation.
- [ExportarEtiqueta.lsp](docs/exportar_etiqueta.md) → Exports all labels to a structured file.
- [LayerControl.lsp](docs/layer_control.md) → Automates layer management for piping layouts.

## 📸 Examples
Screenshots of AutoCAD showing the routines in action are included in the `docs and images` folder.

## ▶️ How to Use
1. Open AutoCAD.
2. Load the routine with `APPLOAD`.
3. Run the custom command (e.g., `DN`).
4. Enjoy automated workflows!

## ⚙️ Compatibility
- Works with **AutoCAD 2014 or newer** (requires trusted paths for secure loading).
- Fully compatible with **AutoCAD 2021+** (Unicode support for labels and text).
- Supported in **AutoCAD LT 2024+** (Windows only, with some limitations).
- Visual Studio Core
